 WHAT THE PIPELINE DOES:

 Input: Paired-end RNA-seq FASTQ files
 ↓
 Alignment: STAR aligns reads to reference genome
 ↓
 Detection: STAR-Fusion detects fusion transcripts
 ↓
 Validation: FusionInspector validates and refines fusions
 ↓
 QC: FastQC/MultiQC generate quality reports
 ↓
 Output: Fusion predictions (TSV) + Reports (HTML)

 YOUR FIRST RUN:

After reading QUICKSTART.md, run:

 nextflow run workflows/main.nf -profile docker \
 --input_fastq_dir ./data/fastqs \
 --ctat_genome_lib_dir ./references/CTAT_LR_v37 \
 --outdir ./results

Results will appear in: ./results/



 DIRECTORY STRUCTURE:

 workflows/ ← Main pipeline script
 modules/ ← Process modules (star_align, star_fusion, etc.)
 conf/ ← Configuration files
 data/ ← Input data (FASTQ files)
 references/ ← Reference genomes & CTAT library
 results/ ← Output results (created after running)
