PIPELINE ARCHITECTURE:
================================================================================

INPUT: Paired-end RNA-seq FASTQ files (gzipped)
 ↓
PREPROCESSING: FastQC quality assessment
 ↓
ALIGNMENT: STAR RNA-seq alignment with chimeric junction detection
 ↓
FUSION DETECTION: STAR-Fusion detects fusion transcripts
 ↓
VALIDATION: FusionInspector refines and validates fusions
 ↓
REPORTING: MultiQC aggregates quality metrics
 ↓
OUTPUT: Fusion predictions (TSV) + Quality reports (HTML)

QUICK START:
================================================================================

1. Setup directories:
 $ cd nf_star_fusion
 $ bash setup.sh
 $ bash validate.sh

2. Prepare data:
 - Add FASTQ files to: data/fastqs/
 - Download CTAT library to: references/CTAT_LR/

3. Run pipeline:
 $ nextflow run workflows/main.nf -profile docker \
 --input_fastq_dir ./data/fastqs \
 --ctat_genome_lib_dir ./references/CTAT_LR_v37 \
 --outdir ./results

================================================================================
EXECUTION PROFILES:
================================================================================

-profile docker → Local with Docker containers
-profile singularity → Local with Singularity containers
-profile slurm → HPC with SLURM scheduler
-profile sge → HPC with Sun Grid Engine
-profile local → Local without containers

Combine: -profile slurm,docker
